AI Toolkit

Six steps from where AI applies to one joined-up AI strategy. Each tool runs in your browser and hands its Excel file to the next.

Nothing is uploaded. Your progress is kept only in this browser.

How the path works. Work through the steps in order, or skip any you do not need. At the end of each tool, download its Excel file and keep it. The AI Strategy View reads all of them together. Use the same organisation or team name in every tool so the files match.

    Also useful

    AI Framework Reference: the shared vocabulary and how the files connect. Read it first if the terms are new.

    Marketing AI Journey Map: the order in which to build each capability. It does not use files, but it helps you act on the Strategy View’s “fix first” list.

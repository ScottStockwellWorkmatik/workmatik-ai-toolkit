      How the sequence is built

      1. Start now. Workflows in the Start here group whose capabilities are not weak, highest priority first, up to the number above.
      2. Quick wins. Workflows in the Quick win group whose capabilities are not weak.
      3. Fix first, then build. Start here and Prepare first workflows held up by a weak capability. The weak capabilities are listed as foundations, earliest journey-map phase first, then by how many workflows they hold up.
      4. Hold. Park workflows, and any workflow in a prohibited tier, which should not go ahead.
      5. Skills. Each foundation capability points to skill domains (table below). A domain is a gap if the average is at or below the threshold. A Marketing Skills Map skill is a gap if it is important but has low coverage.

      A capability that has not been scored is shown as “not yet scored” and is not treated as weak. If no capability file is loaded, no workflow is held back and the page says so.

      What this tool does

      It does not score anything itself. It reads the files from the other tools, matches them on their stable IDs and shows what they say together. Each section needs its own file, and appears only when that file is loaded.

      Which file feeds which section

      Your own data

      Custom roles and activities from the AI Roles Assessment, and your own workflows from the AI Workflow Assessment, are carried in those files and appear here with their own IDs.

      Download

      On the Strategy tab, select Download strategy (XLSX). The file lists the sequence, the workflows, the foundation capabilities, the skills findings and the files it was built from.

      About your data

      This page has no server, no account and no tracking. Files are read in your browser and never uploaded. Nothing is kept when you close or refresh the page, so download the result if you want a record.

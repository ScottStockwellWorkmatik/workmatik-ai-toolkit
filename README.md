# Workmatik AI Toolkit

One page that guides people through the Workmatik AI tools and then joins their Excel files into a single AI strategy.

Tabs: Path (six steps with links and a progress tick-list), Files (load the XLSX files from the other tools), Strategy (sequence, foundations, skills; XLSX download), Rules (editable thresholds), How to use.

Static site, browser-only. Files are read locally and never uploaded. Progress ticks are stored only in the visitor's browser (localStorage). Tool links point to https://scottstockwellworkmatik.github.io/ (edit BASE in js/path.js if the account changes).

Replaces the separate ai-strategy-view repo.
